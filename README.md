# Manilow Web

Sitio web estático de servicios digitales para negocios locales en Madrid: webs, automatización de tareas e IA para pymes.

## Contenido
- Página principal y propuesta de servicios.
- Demos interactivas: reservas de restaurante, citas de clínica, menú QR, presupuesto de taller, asistente de preguntas frecuentes, reseñas y automatizaciones.
- Blog, herramientas y páginas legales (privacidad, cookies, aviso legal).

## Tecnología
HTML, CSS y JavaScript sin dependencias, publicado con GitHub Pages. Pensado para cargar rápido y verse bien en móvil.
